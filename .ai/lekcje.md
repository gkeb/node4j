- [mixins] TTL nie usuwał wygasłych węzłów — zapytanie zakładało etykietę `:TTL` i natywny `datetime` w `ttl`, a węzeł ma etykietę klasy mixinu (`TTLMixin`, ADR 0002) i daty zapisane jako tekst ISO (`model_dump(mode="json")`) → zapytania Cypher na właściwościach modeli dopasowujemy po etykiecie klasy i porównujemy daty przez `datetime(...)`; zachowanie przypina test przez publiczny interfejs (`tests/test_ttl.py`), a nie zapytanie pisane w teście ręcznie. Wystąpienia: 2026-10-11 test
- [projekt] Testowy kontener nie ładował APOC — argument `NEO4J_PLUGINS=["apoc"]` nie dotarł jako poprawny JSON do Dockera, co potwierdził log parsowania → ustawiamy listę pluginów jako literalną zmienną PowerShell i przekazujemy Dockerowi samą nazwę `NEO4J_PLUGINS`. Wzorzec: powloka-posredniczaca-zmienia-argumenty.md. Wystąpienia: 2026-10-11 test
- [projekt] PowerShell przekierował JSON Ruffa jako UTF-16 — założyliśmy, że `>` zachowa kodowanie wyjścia narzędzia, ale kontroler czyta plik jako UTF-8 i odrzucił BOM UTF-16 → wynik zapisujemy jawnie przez `System.IO.File.WriteAllText(..., [System.Text.UTF8Encoding]::new($false))` albo uruchamiamy komendę w powłoce zgodnej z CI. Wzorzec: powloka-posredniczaca-zmienia-argumenty.md. Wystąpienia: 2026-10-12 test
- [aktualizacja-zaleznosci] Ręczne zapytania Cypher w testach miały niecytowane identyfikatory i wklejoną wartość — założyliśmy, że stałe nazwy są bezpieczne bez cytowania, ale Z02 wymaga backticków dla etykiet i właściwości, a wszystkie wartości muszą być parametrami także w wywołaniach procedur → nazwy ujmujemy w backticki, wartości przekazujemy parametrami. Wystąpienia: 2026-10-11 przegląd; 2026-10-12 przegląd
- [aktualizacja-zaleznosci] Fixture sprzątał tylko węzły z oczekiwaną etykietą — założyliśmy, że operacja objęta testem zawsze zapisze poprawną etykietę, więc test wykrywający jej brak mógł zostawić dane → sprzątanie ograniczamy unikalnym, syntetycznym `scope`, bez warunku na zachowanie testowanej operacji. Wystąpienia: 2026-10-12 przegląd; 2026-10-12 przegląd (izolacja zapytania testowego)
- [aktualizacja-zaleznosci] `pytest.raises` nie zgłasza `AssertionError`, gdy oczekiwany wyjątek nie wystąpi — założyliśmy, że `except AssertionError` posprząta trigger po nieoczekiwanym sukcesie, ale pytest zgłasza własny typ błędu → sukces obsługujemy gałęzią `else`, wykonujemy sprzątanie i nie ukrywamy błędu usuwania. Wystąpienia: 2026-10-12 przegląd
- [projekt] `uv run` nie miało dostępu do cache użytkownika w sandboxie — założyliśmy, że polecenie użyje dostępnego `.venv`, ale domyślny cache był poza workspace; test tymczasowy pytest poza repo próbował skanować nadrzędne katalogi i dostał odmowę → ustawiamy `UV_CACHE_DIR` na katalog z `.tmp/` albo uruchamiamy narzędzie bezpośrednio z `.venv`; testy poza workspace uruchamiamy z `--rootdir` repo, `--confcutdir` katalogu testu i bez wtyczki cache (`-p no:cacheprovider`). Wzorzec: sandbox-agenta-odcina-cache-narzedzi.md. Wystąpienia: 2026-10-12 błąd; 2026-10-12 test; 2026-10-12 uv tree; 2026-10-12 błąd (ticket 07)
